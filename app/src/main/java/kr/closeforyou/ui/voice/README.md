# C — UI·TalkBack·음성

소유자: 재호/C, 브랜치: `feature/ui-voice`.

`PopupAnnouncer`, `VoiceCommandInput` 및 사용자 선택 UI를 구현합니다. A의 `app` 패키지는 최초 설정·수집 동의 UI이며, 확장 때 조립 변경을 함께 리뷰합니다. 실제 음성·오버레이는 아직 구현하지 않았습니다.
