# B 실기기 검증 체크리스트

작성: B 준영 · 2026-10-19 (에뮬레이터 결과 추가 2026-10-21, 프리셋 자동 닫기 반영 2026-10-25) · 기준 코드: `main` `e38aac5`

B의 분류·후보 탐색·안전 판단은 지금까지 **합성 데이터로 만든 JVM 단위 시험**과 API 37 에뮬레이터 덤프·계측 시험으로만 검증했습니다. 이 문서는 B가 실제 Android 환경에 대해 전제하는 것을 정리하고, 기기가 생겼을 때 **무엇을 띄워서 어떻게 확인하고, 결과에 따라 무엇을 바꿀지**를 미리 정해 둡니다.

> **실기기 검증은 0건입니다.** API 37 에뮬레이터에서 D의 팝업 재현 앱 화면 구조를 덤프해 P5·P6·P8·P9 일부를 확인했고(2026-10-21, 7절), 덤프 28화면을 A의 실제 필터에 통과시켜 프리셋 3개로 판단해 봤습니다(2026-10-23, [AUTO_CLOSE.md](AUTO_CLOSE.md) 6절). 에뮬레이터 결과이고 실기기·실제 앱 결과가 아닙니다. A 수집기 전체를 거친 결과가 아니어서 A 신호(NEW_WINDOW 등)와 A 적격 근거(`AutoEligibility`)는 아직 모릅니다. main 앱은 B를 아직 부르지 않으므로, 아래 시나리오는 A 조립(#29)과 F9(#42)가 들어온 빌드에서 합니다.

## 2. 시험 원칙 (개인정보·안전)

- **우리가 만든 시험 화면만** 씁니다. 다른 사람의 앱, 로그인된 계정, 실제 결제·메시지 화면은 열지 않습니다(AGENTS 6-8, 검증 계획 C12 윤리).
- 기록하는 것은 **시험 화면 노드의** className, viewId 이름, 버튼 text/contentDescription, clickable·enabled, 동작(CLICK/DISMISS), 신호(NEW_WINDOW 등), B의 분류·후보·결정뿐입니다. 실제 앱 화면의 스크린샷·화면 원문은 남기지 않습니다(AGENTS 6-8·6-9). 개인정보가 없는 **우리 합성 시험 화면**의 스크린샷·노드 덤프만 팀 공유용으로 남길 수 있고, 앱 로그에는 어떤 경우에도 화면 원문을 쓰지 않습니다.
- 실제 클릭은 하지 않습니다. A 게이트와 실행기가 연결되기 전까지 B 결과는 **판단 결과만** 기록합니다. F9가 들어온 뒤에도 자동 닫기 시험(S14~S20)은 **우리 시험 앱에서만**, 프리셋은 시험할 때만 켜고 끝나면 끕니다.
- 합성 화면은 B 혼자 공용 시험 앱에 넣지 않습니다. `capture-test-host`(A 관리)나 D의 시험 앱에 추가할 때는 담당자와 먼저 합의합니다.

## 5. 결과에 따른 판단 기준

- **S4가 실제 앱 사례에서 자주 보이면 (P6 거짓):** "클릭 가능한 부모 + 라벨 있는 자식 하나" 규칙을 A와 함께 설계합니다. 조건: 자식이 정확히 하나, 그 자식 말고 다른 글자가 없음, 부모·자식 모두 팝업 소속, A 게이트도 같은 규칙으로 재검증. 라벨 계약 PR과 같이 다룹니다.
- **S6·S8에서 Dialog 노드가 없으면 (P8 거짓):** A에게 같은 창 덮개의 **팝업 영역(경계·루트 경로)을 공개 DTO로** 받는 계약을 제안합니다. B 혼자 영역을 추측하지 않습니다.
- **S8에서 `aria-label`이 contentDescription으로, `×`가 text로 오면:** 노드 단위 규칙(모든 라벨이 같은 역할)상 거부됩니다. 이 경우 text의 단독 `×`를 "장식"으로 볼지 라벨 계약에서 A·C와 정합니다. 위험 방향이므로 기본은 거부를 유지합니다.
- **S12가 흔하면:** 전체 화면 광고는 지금 합의상 후보 0개입니다. 사용자 명시 선택 경로만 열지 A와 다시 논의합니다(자동 실행은 계속 금지).
- **S14에서 적격 근거가 자주 빠지면 (P12):** 어떤 검사가 빠지는지 A와 보고, B 조건을 느슨하게 하지 않습니다(빠지면 묻기가 안전 쪽).
- **S16에서 `LEFT_APP`이 관측되지 않으면 (P14):** 가짜 닫기 뒤 정지가 작동하지 않으므로 운영 자동 닫기를 켜지 않습니다.
- **S18에서 사기 팝업이 하나라도 닫히면 (P15):** 그 문구를 사전에 넣고 계측 시험으로 고정하기 전까지 프리셋 자동 닫기를 켜지 않습니다.
- 어떤 결과든 **위험 범주 잘못 허용 0**(라벨 계약 v1, 분류 평가, 결정·사기 자동 닫기 0)을 깨는 변경은 하지 않습니다.
