# A — Android 접근성 코어

소유자: 우진/A, 브랜치: `feature/core`.

서비스·실제 접근성 노드·보호 검사·팝업 후보 감지·토큰 무효화와 미래 캡처/행동 게이트를 소유합니다. Android 노드와 이벤트는 동기 처리 안에서만 읽고 불변 `core.model` DTO로 복사합니다. B·C·D에 노드를 전달하거나 일반 로그에 원문을 쓰지 않습니다.

현재 팝업 후보는 광고 판정·클릭 허가가 아닙니다. 캡처·OCR·실제 행동은 TODO이며 권한과 능력을 미리 확대하지 않습니다. [연동 방법](../../../../../../../docs/TEAM_INTEGRATION.md)과 [상태](../../../../../../../docs/DEVELOPMENT_STATUS.md)를 따릅니다.
