# 합성 Mock·연동 예제

`mock`은 개인정보가 없는 fixture와 실제 행동을 수행하지 않는 포트 대체물, `mock/IntegrationExample.kt`는 B·C·D 연동 예제입니다. 실제 팝업 분류·음성·녹음·Room·클릭 엔진을 대신하지 않습니다.

개발·단위 시험은 fixture로 시작하고 실제 접근성/TalkBack 검증은 별도로 기록합니다. Mock을 런타임 자동 클릭 경로에 연결하지 않습니다. [사용 방법](../../../../../../../docs/TEAM_INTEGRATION.md)을 참고하세요.
