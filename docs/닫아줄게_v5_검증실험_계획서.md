# 닫아줄게 v5 검증 실험 계획서 — 문서 경로 안내

필수 검증 계획의 저장소 원문은 **[검증 실험 계획.md](검증%20실험%20계획.md)**입니다. 이 안내 파일은 `AGENTS.md`와 개발 지시에서 지정한 경로를 연결합니다. 원문을 복제하거나 수정하지 않으며, 개발 전 원문 전체를 읽어야 합니다.

[AGENTS.md](../AGENTS.md)의 최신 결정에 따라 F6 영상 내용·줄거리 설명은 제외합니다. 원문 C07은 F5 영상 여부·광고 여부·안전 스킵 검증을 유지하되 영상 줄거리·장면 설명 평가는 수행 범위에서 제외합니다. C10의 영상 설명 요청도 현재 명령 요구사항이 아닙니다. F10 실제 음성 안내·재청취, F12 기억과 취소, F13 누르고 말하기 명령은 계속 필수 검증 대상입니다.

이 안내는 실험 결과가 아닙니다. 실제 시행 여부와 후속 시험 항목은 [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md)에 구분하여 기록합니다. 본문에 제시된 성능 목표나 API 가능성을 구현 성공으로 해석하지 않습니다.
