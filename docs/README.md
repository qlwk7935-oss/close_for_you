## 최신 결정 우선순위

`AGENTS.md`와 이번 개발 지시의 최신 팀 결정이 원문보다 우선합니다.

- F6 영상 내용·줄거리 설명은 제외합니다. 원문에 남은 F6, `무슨 영상이야`, 영상 설명 실험 항목은 현재 요구사항으로 사용하지 않습니다.
- F5 영상 광고 감지·안전 처리는 유지합니다. 영상이라는 사실과 광고라는 분류는 별도로 판단해야 합니다.
- F10 TalkBack 음성 안내, F12 사용자 선택 기억, F13 음성 명령은 필수입니다. 현재 미구현은 제외 결정이 아니라 명시된 후속 개발 과제입니다.
- F13은 누르고 말하기 방식입니다. 상시 청취나 사용자 요청 없는 녹음을 구현하지 않습니다.
- 동일 팝업 반복 자동화에도 사용자 허락·정확한 본문/구조/대상 일치·현재 보호 상태 재검사가 필요합니다.

기존 원문과 최신 결정의 차이를 숨기지 않기 위해 원문은 덮어쓰지 않고 이 안내 및 개발 상태 문서로 현재 범위를 기록합니다. 문서상의 설계나 JVM 단위 시험 통과는 실기기에서 동작했다는 증거가 아닙니다.
