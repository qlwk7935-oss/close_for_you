# 자동 닫기 안전 시험 준비 (D)

담당: 동준/D. B [실기기 체크리스트](../app/src/main/java/kr/closeforyou/decision/REAL_DEVICE_CHECKLIST.md) 3절 S14~S20을 **D 팝업 재현 앱**으로 돌리기 위한 준비입니다. 기대 결과는 B 문서(현재 B 코드 기준)를 그대로 옮겼고, 바뀌면 B 문서를 따릅니다.

**상태: 준비만 했습니다. 실측은 0건입니다.** 재현 화면(P19~P23)과 정답지는 CI 시험으로 일관성만 확인했습니다.

## 1. 원칙

- **운영 자동 실행은 켜지 않습니다.** 운영 빌드의 자동 닫기(`PresetAutoCloseFeature.live`), 자동 건너뛰기, F12 자동 반복, REVALIDATING은 계속 OFF입니다.
- 자동 닫기 시험은 A F9·적격 근거(`AutoEligibility`)·C 자동 닫기 동의가 연결되고, A·C가 정한 **시험용 빌드**에서만 합니다. 그 전에는 같은 화면에서 **B 판단(`next`·`source`·사유)만** 기록합니다(클릭 없음).
- 화면은 **재현 앱(`kr.closeforyou.popuptest`)만** 씁니다. 다른 앱·로그인된 계정·실제 결제 화면은 열지 않습니다.
- 프리셋은 시험할 때만 켜고 끝나면 끕니다. 앱별 허용 목록에도 재현 앱만 넣습니다.
- 기록에는 화면 원문을 쓰지 않습니다. 시나리오 ID, 고정 코드(`next`·`source`·사유·`attempted`·`status`·`outcome`), 안내 종류만 적습니다.

| S | 재현 앱 | 절차 | 기대(B 문서) | 실패 |
|---|---|---|---|---|

| S16 | **P19** 가짜 닫기 | 프리셋 ①, P19 → 홈으로 나감 → 재현 앱에서 P01 | 첫 1회 누름은 알려진 한계(겉으로 구별 불가). `LEFT_APP` 관측 뒤 같은 앱은 세션 동안 묻기 | `LEFT_APP` 뒤에도 자동 닫기 계속, `LEFT_APP` 미관측 |

| S18 | **P21** 당첨, **P22** 감염 | 프리셋 ①·②·③ 모두 | 어떤 프리셋에서도 누르지 않음 + 경고(`SUSPICIOUS_CONTENT`) | 앱이 어떤 버튼이든 누름, 경고 없음 |
| S19 | P01 + 안내 불가 | C의 `announcementAvailable=false` 기준이 정해진 뒤 | 묻기(`FEEDBACK_UNAVAILABLE`), 조용히 닫지 않음 | 안내 없이 닫음 |

S19는 재현 앱을 바꿀 필요가 없습니다(안내 가능 여부는 C 쪽 상태).

## 3. 함께 볼 안전 차단

| 묶음 | 재현 앱 | 앱이 누르면 안 되는 것(logcat 0줄) |
|---|---|---|
| 가짜 닫기 | P06 가짜 X, P19 앱 밖으로 보내는 '닫기' | `P06:btn_fake_x`, `P06:ad_landing_opened`. P19는 첫 1회 `btn_fake_close`·`left_app`까지 알려진 한계, 두 번째부터 0 |
| 연속 광고 | P12 광고→공지→동의, P17 닫기+건너뛰기, P20 4개 | `P12:btn_allow`(동의창 연쇄 클릭), `P17:btn_skip`, P20 4번째 `btn_close` |
| 사기 의심 | P21, P22 | `P21:btn_prize_claim`, `P22:btn_scan_now`, `ad_landing_opened`, 그리고 두 화면의 `btn_close`도 앱이 누르면 실패 |
| 결정·민감 | P08~P11 | 모든 버튼 |

`qa_metrics.py --logcat`이 정답지의 자동 금지 버튼·앱 허용 버튼과 대조합니다(정답지 `forbidden_targets`, `app_allowed_target`).

## 4. 클릭 없는 첫 통합에서 미리 볼 것

- P21·P22: 누르기 버튼 없음. 경고 안내 여부는 C 기준대로 기록합니다.
- P19: '닫기' 누르기 버튼이 보이는 것이 현재 예상입니다(가짜 닫기와 구별 불가). 비실행으로 끝나야 합니다.
- P20: 첫 광고만 봅니다. 다음 광고는 '닫기'를 눌러야 나오므로 클릭 단계에서 봅니다.
- P23: 3초 전에는 누르기 버튼 없음, 생긴 뒤 '닫기'.
- 정답지 `int1_kind`: P19·P20 광고, P21·P22 모름(B 내부 분류는 SUSPICIOUS), P23 쿠폰.

## 5. 기록

[`templates/experiment_results.csv`](templates/experiment_results.csv) 한 줄에 시행 하나. `preset`(켠 프리셋)과 `auto_executable`(그 시행에서 서비스가 실제로 자동 실행할 수 있었는지)을 **따로** 적습니다. 정답지 `preset_*`는 목표일 뿐 실행 가능 여부가 아닙니다. 관측한 B 분류는 `observed_kind`에 적습니다. 자동 닫기 칸은 B 체크리스트 4절 양식(켠 프리셋, 적격 근거 5개 중 있던 것, F9 결과, 안내 종류)을 `notes`에 고정 코드로 적습니다. 미실시를 성공으로 쓰지 않습니다.
