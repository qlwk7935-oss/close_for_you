# 닫아줄게 통합 설계 v5 — 문서 경로 안내

필수 설계 문서의 저장소 원문은 **[통합설계.md](통합설계.md)**입니다. 이 안내 파일은 `AGENTS.md`와 개발 지시에서 지정한 경로를 연결합니다. 원문을 복제하거나 수정하지 않으며, 개발 전 원문 전체를 읽어야 합니다.

원문보다 [AGENTS.md](../AGENTS.md)의 최신 팀 결정을 우선합니다. F6 영상 내용·줄거리 설명은 제외하고 F5 영상 광고 감지·안전 처리는 유지합니다. F10 음성 안내, F12 사용자 선택 기억, F13 누르고 말하기 음성 명령은 필수입니다. 원문의 F6 및 영상 설명 명령은 현행 구현 범위에 포함하지 않습니다.

실제 구현 범위는 [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md), 담당자별 연동은 [TEAM_INTEGRATION.md](TEAM_INTEGRATION.md)를 확인하세요.
