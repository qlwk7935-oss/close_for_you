# 최종 시연 진행표 (D)

담당: 동준/D. 시연 영상(팝업처리도우미 × 가상 쇼핑몰 "모아마켓")과 **같은 순서로 실제 앱을 돌리기 위한** 진행표입니다. 장면마다 띄울 팝업, 초기화 방법, 확인 기준을 적었습니다.

**상태: 준비만 했습니다. 실측은 0건입니다.** 재현 화면(P25~P32)과 정답지는 CI 시험으로 일관성만 확인했습니다. 시연 영상은 연출 앱으로 찍었고("실제 감지·분류·자동 실행은 없어요"), 아래 "지금 코드 예상"은 실제 앱 코드 기준입니다. 둘이 다른 곳은 5절에 모았습니다.

## 1. 원칙

- 화면은 **재현 앱(`kr.closeforyou.popuptest`)의 모아마켓 화면만** 씁니다. 가상 쇼핑몰이며 실제 상품·결제·로그인·네트워크는 없습니다.
- 운영 자동 실행은 켜지 않습니다. 자동 닫기 장면은 A·C가 정한 **시험용 빌드**에서만, 프리셋은 시험 중에만 켭니다(자동 닫기 안전 시험 준비 문서와 같음).
- 기록에는 화면 원문을 쓰지 않습니다. 시나리오 ID, 고정 코드, Y/N만 적습니다.

## 2. 준비

```bash
./gradlew :app:assembleDebug :popup-test-app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r -t popup-test-app/build/outputs/apk/debug/popup-test-app-debug.apk
```

- 팝업 띄우기: `adb shell am start -n kr.closeforyou.popuptest/.PopupScenarioActivity --es scenario <ID>` (아래 `[띄우기] <ID>`).
- 화면 위 제목은 ID만 보입니다. 장면 이름은 자막으로 넣습니다.
- 측정 구간 기록이 필요하면 `bash tools/int1_session.sh <ID> <시행>`을 씁니다.

### 초기화 (장면마다)

| 대상 | 방법 |
|---|---|
| 재현 앱 | `adb shell am force-stop kr.closeforyou.popuptest` |
| 닫아줄게 기억 | 설정 → 기억 → [전체 삭제] (`RuleStorage.eraseAll`) |
| 프리셋·자동 닫기 | 설정 → 팝업 처리 방식에서 장면이 정한 값으로. 끝나면 자동 닫기 끔 |
| 세션 기록(같은 팝업 다시, 속도 제한) | 닫아줄게 접근성 서비스를 껐다 켬 |

## 4. 정답지와 지표

- 장면마다 정답지(`docs/templates/popup_answer_key.csv`) P25~P32 행이 기대 결과입니다. `preset_*`는 목표, `int1_*`는 지금 코드 예상입니다.
- 결과는 [`templates/experiment_results.csv`](templates/experiment_results.csv)에 시행 한 번당 한 줄. `experiment_id`는 `DEMO-<장면>`(예: `DEMO-3-2`).
  - `preset`, `auto_executable`(그 시행에서 서비스가 실제로 자동 실행할 수 있었는지), `observed_kind`(관측한 B 분류)를 따로 적습니다.
  - `info_correct`: 안내 문장이 화면과 맞았는지 Y/N(예: 닫지 않았는데 "닫았어요"라고 하면 N). 문장 원문은 적지 않습니다.
- 집계: `python3 tools/qa_metrics.py demo_results.csv --logcat popuptest.log`
  - **오클릭 0건**, **금지 버튼 0건**, **목표 밖 자동 처리 0건**이어야 통과입니다.
  - 안내 정확도는 보고서 "내용 이해 정확도"(`info_correct` 비율)로 봅니다.

## 5. 영상과 지금 코드가 다른 곳 (결정 필요)

## 6. 같이 정할 것 (D 의견)

- **앱 이름·아이콘**: 영상의 "팝업처리도우미"와 실제 앱이 같아야 시연에서 이질감이 없습니다. 이름·아이콘은 C 화면·앱 설정이 바뀌므로 재호·우진 결정이 먼저이고, 재현 앱 문서와 진행표는 결정에 맞춥니다.
- **"버튼으로 바로 이동" 기본값**: **끔**을 제안합니다. 켜면 선택 창이 뜨자마자 TalkBack 초점이 저절로 옮겨지는데, 사용자가 예상하지 못한 움직임이고 B 원칙(초점 변경 없음)과도 부딪힙니다. 원하는 사람만 켜게 합니다.
