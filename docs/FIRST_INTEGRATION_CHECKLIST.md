# 첫 통합 실측 검증표 (D)

담당: 동준/D. 우진(A)의 첫 통합 실측(Android Studio API 37 에뮬레이터)을 같은 기준으로 기록·집계하기 위한 표입니다. C 화면·TalkBack 세부는 재호의 `docs/c-notes/c-test-checklist.md`를 함께 씁니다.

**이 문서는 빈 표입니다.** 아직 아무 실측도 하지 않았습니다. 확인하지 않은 칸은 "통과"로 채우지 않고 **못 봄**으로 둡니다.

## 1. 이번 실측의 목표와 금지

목표: **안전한 팝업 감지 → 분류 → 사용자 안내 → 명시적 선택 → 비실행 결과**까지 확인합니다(A 10/22).

| 반드시 0건 | 확인 방법 |
|---|---|
| 앱이 실제로 누른 버튼(클릭·제스처·자동 닫기) | 재현 앱 logcat에 시험자가 직접 누르지 않은 `시나리오:버튼` 줄이 없음, `qa_metrics.py --no-click` 안전 실패 0 |
| 광고 페이지 도착(`ad_landing_opened`) | logcat |
| 위험 화면(P08~P11)에서 누르기 버튼 제안 | C 선택 창 확인, `offered_press=N` |
| 민감 화면(P11) 분석·안내 | 선택 창·자체 TTS 없음, A 차단 |
| 화면 원문이 로그에 남음 | `adb logcat` 전체에서 재현 앱 문구(예: "가을 할인 쿠폰") 검색 시 0건 |

- 실제 클릭이 없으므로 사용자가 [누르기]를 골라도 결과는 **비실행**(`NOT_EXECUTED`)이어야 합니다. "닫았어요"라고 말하면 실패입니다.
- F9 `productionReady=false`, 자동 반복 OFF(`RepeatAutomation.EXECUTION_ENABLED=false`), F12 기억 저장은 연결하지 않은 상태가 전제입니다.

## 2. 준비

```bash
./gradlew :app:assembleDebug :popup-test-app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -t popup-test-app/build/outputs/apk/debug/popup-test-app-debug.apk
adb logcat -c
adb logcat -s PopupTest > popuptest.log      # 별도 창에서 켜 두기
```

1. 닫아줄게 접근성 서비스 켜기, 앱별 허용 목록에 `kr.closeforyou.popuptest` **직접** 추가(초기 목록은 비어 있음).
2. TalkBack은 사람이 설정에서 켭니다(에뮬레이터 TalkBack 결과는 참고용, "통과"는 실기기만).
3. 시나리오 열기: `adb shell am start -n kr.closeforyou.popuptest/.PopupScenarioActivity --es scenario P01`
4. **측정 중에는 시험자가 팝업 버튼을 직접 누르지 않습니다.** 끝낸 뒤 닫을 때는 시스템 뒤로 가기를 쓰거나, 누른 경우 비고에 "사람"이라고 적습니다(logcat에는 누가 눌렀는지 남지 않음).

## 3. 기록

[`templates/experiment_results.csv`](templates/experiment_results.csv)에 시행 한 번당 한 줄. `experiment_id`는 `INT1`.

| 열 | 이번 실측에서 |
|---|---|
| `detected` | A가 팝업으로 감지해 C 선택 창이 떴는지 Y/N |
| `outcome` | 선택 창에서 [누르기]를 골랐으면 `NOT_EXECUTED`, 안내만 했으면 `ANNOUNCED_ONLY`, A가 막았으면 `BLOCKED`, 감지 못 했으면 `MISSED` |
| `offered_press` | C가 누르기 버튼(`'닫기' 버튼 눌러 주기` 등)을 보여 줬는지 Y/N |
| `clicked_target` | **비워 둡니다.** 이번 단계에 앱이 누른 버튼은 없어야 합니다 |
| `notes` | 화면 원문 없이. 예: "TTS 0.7초 뒤 1회", "사람이 뒤로 가기로 닫음" |

집계:

```bash
python3 tools/qa_metrics.py int1_results.csv --logcat popuptest.log --no-click
```

`--no-click`은 `AUTO_HANDLED`·`USER_CONFIRMED` 행을 안전 실패로 보고 종료 코드 1을 돌려줍니다. 이 단계에서는 "잘못 거부" 대신 **누르기 제안률**과 **잘못 제안**(앱 허용 버튼이 없는데 누르기 버튼을 보여 줌)을 봅니다.

## 4. 시나리오별 기대값

분류는 B가 정하므로 "B가 광고로 분류하면"처럼 조건부입니다. 누르기 버튼 이름은 A 실행 관문 라벨(`닫기`·`건너뛰기` 등)과 일치할 때만 보입니다(C 검사표 2-0).

| ID | 우선 | 감지 | 누르기 버튼 제안 | [누르기] 선택 후 | 결과(`outcome`) | 결과 칸 |
|---|---|---|---|---|---|---|
| **P01** 라벨 있는 광고 | 1순위 | 예 | ['닫기'] 1개 | 비실행 안내, 다시 누르지 않음, logcat 줄 없음 | `NOT_EXECUTED` | ☐통과 ☐실패 ☐못 봄 |
| **P13** WebView 모달 | 1순위 | A 판단(실측 확인) | 없음(B `IMPORTANT_DECISION` 안전 거부 유지, A 10/22) | - | `BLOCKED` 또는 `ANNOUNCED_ONLY` | ☐통과 ☐실패 ☐못 봄 |
| P04 라벨 없는 X | 2순위 | 예 | **없음**("대신 닫을 수 없어요") | - | `ANNOUNCED_ONLY` | ☐통과 ☐실패 ☐못 봄 |
| P06 가짜 X | 2순위 | 예 | ['닫기'] 1개, 가짜 X는 절대 없음 | 비실행 | `NOT_EXECUTED` | ☐통과 ☐실패 ☐못 봄 |
| P08 가짜 결제 | 2순위 | 예 | **없음** | - | `ANNOUNCED_ONLY` | ☐통과 ☐실패 ☐못 봄 |
| P09 구독 '취소' 함정 | 2순위 | 예 | **없음**('취소'는 관문 라벨 아님) | - | `ANNOUNCED_ONLY` | ☐통과 ☐실패 ☐못 봄 |
| P10 가짜 동의 | 2순위 | 예 | **없음** | - | `ANNOUNCED_ONLY` | ☐통과 ☐실패 ☐못 봄 |
| P11 가짜 로그인 | 2순위 | A 차단 | 선택 창 자체 없음 | - | `BLOCKED` | ☐통과 ☐실패 ☐못 봄 |
| P12 연속 팝업 | 3순위 | 창마다 | 광고·공지 ['닫기'], 셋째 동의창 **없음** | 비실행 | 창별 한 줄 | ☐통과 ☐실패 ☐못 봄 |
| P14 화면 전환 | 3순위 | **아니오**(오탐 확인) | - | - | `ANNOUNCED_ONLY`면 오탐 | ☐통과 ☐실패 ☐못 봄 |
| P15 토스트 | 3순위 | **아니오** | - | - | 감지되면 오탐 | ☐통과 ☐실패 ☐못 봄 |
| P16 영상 광고 | 3순위 | 예 | 카운트다운 중 **없음**, 끝난 뒤 ['건너뛰기'] | 비실행 | `NOT_EXECUTED` | ☐통과 ☐실패 ☐못 봄 |
| P17 닫기+건너뛰기 | 3순위 | 예 | 두 개 또는 B 정책에 따라 없음(실측 기록) | 비실행 | `NOT_EXECUTED`/`ANNOUNCED_ONLY` | ☐통과 ☐실패 ☐못 봄 |
| P18 시간 문구 함정 | 3순위 | 예 | ['닫기']만, **'건너뛰기' 없음**(시간 문구 오인 시 실패, B #20) | 비실행 | `NOT_EXECUTED` | ☐통과 ☐실패 ☐못 봄 |

1순위만으로도 실측 1차 보고는 가능합니다. 2·3순위는 시간이 되는 만큼 하고 나머지는 "못 봄"으로 둡니다.

## 5. 공통 확인(시나리오와 별개)

| 항목 | 확인할 것 | 결과 |
|---|---|---|
| 오버레이 표시·제거 | 선택 창이 뜨고, 닫거나 팝업이 사라지면 창도 사라짐. 사라진 뒤 화면 터치가 막히지 않음 | ☐통과 ☐실패 ☐못 봄 |
| 오래된 선택 | 팝업이 바뀐 뒤 이전 선택 창 버튼을 눌러도 새 화면에 영향 없음(A 오래된 선택 차단, C #18 콜백) | ☐통과 ☐실패 ☐못 봄 |
| TTS | 창이 뜨고 약 0.7초 뒤 1회. 반복·중첩 없음 | ☐통과 ☐실패 ☐못 봄 |
| TalkBack | 선택 창 버튼 이름·순서를 읽음, 닫힌 뒤 포커스가 앱 본문으로 돌아옴 | ☐통과 ☐실패 ☐못 봄 |
| 서비스 재연결 | 접근성 서비스를 껐다 켜도 같은 시나리오에서 같은 결과 | ☐통과 ☐실패 ☐못 봄 |
| 로그 원문 | 전체 logcat에 재현 앱 화면 문구가 없음 | ☐통과 ☐실패 ☐못 봄 |
