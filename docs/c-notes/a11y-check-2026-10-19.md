# 접근성 점검 — 2026-10-19 (C, 낮 무인 작업)

> 10/18 점검(`a11y-check-2026-10-18.md`)에 이어서 **명도 대비**와 **큰 글꼴**을 본다.
> LG 벨벳이 연결되지 않아(12:07 `adb devices` 빈 목록) **실기기 큰 글꼴 점검은 하지 못했다.** 코드 검토로 찾은 위험 1개를 고쳤고, 실기기 확인은 "사람이 확인할 것"에 남긴다.

## 1. 명도 대비 (WCAG 2.1 1.4.3 글자 4.5:1 / 1.4.11 비글자 3:1, KWCAG 5.3.3)

### 색 출처
- C 화면(선택 창·설정)은 색을 직접 지정하지 않고 `MaterialTheme {}` 기본값(Material3 **라이트** 기본 색)을 쓴다.
- 값은 추측하지 않고 **프로젝트가 실제로 쓰는 `material3-android 1.3.2`의 `PaletteTokens`·`ColorLightTokens`를 `javap`로 읽어** 확인했다.
  - primary `#6750A4`, onPrimary `#FFFFFF`, surface·background `#FEF7FF`, onSurface `#1D1B20`, onSurfaceVariant `#49454F`, outline `#79747E`, surfaceContainerHigh `#ECE6F0`(확인 창), surfaceContainerHighest `#E6E0E9`(스위치 꺼짐 트랙)
- 선택 창은 `Surface(tonalElevation = 6.dp)`라서 배경에 primary가 약 10.8% 섞인다 → `#EEE5F5` (Compose `surfaceColorAtElevation` 공식으로 계산)
- 계산 스크립트: WCAG 상대 휘도 공식 (sRGB 선형화 → 0.2126R+0.7152G+0.0722B)

### 발견 — 다크 모드
- `MaterialTheme {}`에 색 구성을 넘기지 않아서 **기기가 다크 모드여도 C 화면은 항상 밝은 색**이다. 대비는 충분하지만, 저시력 사용자 중 눈부심 때문에 다크 모드를 쓰는 사람에게 갑자기 밝은 선택 창이 뜬다.
- 앱 전체 테마는 A(`MainActivity`)와 맞춰야 하는 결정이라 **이번에는 바꾸지 않았다** → 보고서 "결정할 것".

## 2. 큰 글꼴

### 코드 검토로 찾은 위험과 수정
| 위치 | 위험 | 수정 |
|---|---|---|
| 다른 앱 위 선택 창 (`AccessibilityChoiceOverlay`) | 창 높이가 `WRAP_CONTENT`이고 **스크롤이 없었다.** 글꼴 200%에서 버튼이 4~5개(누르기 2 + 버튼으로 이동 + 다시 읽기 + 그대로 두기)면 화면보다 길어져 **아래 버튼이 잘릴 수 있다** | 선택 창에 `verticalScroll` 추가 (TalkBack은 다음 항목으로 갈 때 자동으로 스크롤). 창이 화면 높이를 다 쓰면 상태 표시줄을 가리지 않게 `statusBarsPadding` 추가 |
| 설정 화면 | 이미 `verticalScroll` | 변경 없음 |
| 미리보기 (debug) | 이미 `verticalScroll` | 변경 없음 |
| 버튼 높이 | 모두 `heightIn(min = 48.dp)` (최소값이라 글꼴이 커지면 함께 커짐) | 변경 없음 |
| 글자 크기 | 모두 `sp` 단위 Material 글꼴 (고정 dp 글자 없음) | 변경 없음 |

### 실기기 점검 (하지 못함)
- 계획: LG `settings put system font_scale 2.0` → 미리보기·설정·오버레이 → 즉시 원래 값 복구.
- 오늘 LG 연결이 없어 **미검증.** 오버레이 창의 상태 표시줄·내비게이션 바 여백(`WindowInsets`)이 접근성 오버레이 창에서 실제로 어떻게 들어오는지도 **실기기 확인 필요.**

## 3. 사람이 확인할 것
1. LG 또는 S26에서 글꼴 크기 최대 + 화면 크기 최대: 선택 창(시나리오 6 = 닫기·건너뛰기 둘 다)이 잘리지 않는지, 스크롤되는지, TalkBack 쓸어넘기기로 마지막 버튼까지 가는지
2. 같은 조건에서 설정 화면의 "기억 전체 삭제"와 확인 창 버튼이 보이는지
3. 다크 모드에서 밝은 선택 창이 불편한지 (사용자 의견)
