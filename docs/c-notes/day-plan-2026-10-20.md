## 2. 배경

- 음성 부품은 있다: `ui/voice/command/` (`OnDeviceVoiceCommandInput`, `KoreanVoiceCommandMatcher`, `VoiceChoiceMapper`). 그런데 **실제 선택 창(오버레이)에는 연결 안 됨** — debug `ChoicePreviewActivity`에서만 씀.
- `PopupAnnouncer`에 `repeatLast`·`stop`이 있지만 선택 창에 버튼이 없다.
- `RECORD_AUDIO`는 **debug 매니페스트에만** 있다. main 매니페스트는 A 파일 → 고치지 않고, 권한이 선언·허용되지 않았으면 [말하기]를 숨기는 방식으로 만든다. 보고서에 "A에게 main 매니페스트 RECORD_AUDIO 요청" 적기.
- 팀 결정 (우진 10/20): [앞으로 항상 닫기]·[다시 묻지 않기]·거부 이유 안내·[버튼으로 이동]은 **계속 꺼 둔다** (플래그 바꾸지 말 것). Mock 성공 ≠ 실제 성공.
- 음성 정책 (CLAUDE.md 3장): 말하기 버튼을 누를 때만 듣는다. 닫기·건너뛰기·다시 읽기·그대로 두기는 바로 요청 가능(그래도 B 정책·A 게이트 거침). "항상 닫아"류는 버튼 이름을 읽어 주고 **화면 탭으로 확정**. 결제·구매·구독·삭제·권한·동의·로그인은 음성으로 대신 누르지 않는다. TalkBack 포커스는 옮기지 않는다.

## 3. 단계

시작 전: `git status`가 깨끗하고(이 지시서 하나만 미추적이면 정상) `feature/ui-voice`인지 확인.

### 1단계 — 선택 창 [말하기] 버튼 + 음성 → 선택 연결
- `ChoicePromptContent`에 [말하기] 버튼(48dp 이상, contentDescription 명확). 누를 때만 `VoiceCommandInput` 시작, 듣는 중 상태 표시·liveRegion 안내("듣고 있어요" 등), 다시 누르면 취소.
- 인식 결과 → `VoiceChoiceMapper` → 현재 선택 창에 **보이는 선택지**와만 연결 (안 보이는 선택은 실행 안 함). 결과는 `PopupChoiceFlow`의 기존 선택 처리 경로로.
- 못 알아들음·무관한 말 → "알아듣지 못했어요" 류 안내 후 창 유지. 아무 말 없음 → 조용히 끝.
- 듣는 동안 우리 TTS는 멈춘다(마이크에 TTS가 들어가지 않게). TalkBack 소리 문제는 보고서에 "실기기 확인 필요".
- 기능 플래그(예: `VoiceButtonFeature.enabled`, 기본 true) + 5단계 설정 값으로 숨길 수 있게.

### 2단계 — 마이크 권한 처리
- 권한 확인은 순수 인터페이스로 분리(JVM 시험). 권한 없음 → [말하기] 숨기고, 창의 마지막 줄에 짧은 안내(또는 안내 없이 숨김 — 보고서에 선택 이유).
- 설정 화면에 "마이크" 항목: 상태 표시 + [마이크 허용] 버튼(Activity 안에서만 권한 요청, 서비스 오버레이에서는 요청하지 않음). 매니페스트에 선언이 없으면 버튼 대신 "아직 이 앱 버전에서는 음성 명령을 쓸 수 없어요" 류 안내.
- 기존 의존성 안에서 가능한 API만 (`ActivityResultContracts.RequestPermission` 등). 새 라이브러리 금지.

### 3단계 — [다시 듣기]·[그만 말하기]
- 선택 창에 두 버튼. `PopupAnnouncer.repeatLast()`/`stop()` 연결. 다시 들을 게 없으면 기존 `ui_announce_nothing_to_repeat`.
- 버튼이 너무 많아지면 TalkBack 탐색 순서를 정리(선택지 → 말하기 → 다시 듣기 → 그만 말하기). 접근성 점검 결과를 보고서에.

### 4단계 — 음성 정책 반영
- 음성 → 선택 연결에 정책 테이블을 둔다 (순수 함수 + 시험):
  - 바로 요청: CLOSE_ONCE, SKIP_ONCE, READ_CONTENT, KEEP_OPEN (해당 선택지가 보일 때만)
  - 탭 확정 필요: "항상 닫아"·"다시 묻지 마"류 → 지금은 플래그가 꺼져 있으므로 "화면에서 직접 골라 주세요" 류 안내만, 실행 없음
  - 거절: 결제·구매·구독·삭제·권한·동의·로그인 요청 → "그 버튼은 대신 누를 수 없어요" 류, 실행 없음
- 문구는 `ui_voice_strings.xml`, `ui_` 접두사. 인식 문장 원문을 안내문에 그대로 넣지 않는다.

### 5단계 — 설정 화면 음성 명령 켜기/끄기
- `UiVoiceSettings`에 음성 명령 켜기(기본 켜짐). 끄면 [말하기] 숨김. 마이크 항목과 같은 구역.

### 6단계 — 정리·보고서
- 전체 빌드·시험·lint. 병합 매니페스트(main/debug)에서 INTERNET 없음·권한 변화 확인.
- 보고서: 쉬운 요약 5줄 / 단계별 결과 / 바뀐 파일 / 추천 커밋 묶음·메시지 / 사용자가 결정할 것(선택지+추천) / 팀 메시지 초안(우진 RECORD_AUDIO 요청 포함) / 실기기 확인할 것(S26 음성, LG TalkBack 순서) / 사용량(시작·끝).
- 끝날 때 `feature/ui-voice`, 미커밋 상태 확인.
